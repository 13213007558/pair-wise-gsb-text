= Text

A collection of text algorithms.

== Usage

  require 'text'

=== Levenshtein distance

  Text::Levenshtein.distance('test', 'test')
  # => 0
  Text::Levenshtein.distance('test', 'tent')
  # => 1
  Text::Levenshtein.distance('test', 'testing')
  # => 3
  Text::Levenshtein.distance('test', 'testing', 2)
  # => 2

==== Levenshtein dictionary index

A trie index can avoid recalculating the states shared by dictionary prefixes.
It retains each original entry even when several entries normalize to the same
text. Equal distances are ordered by the supplied priority, then by input
order.

  dictionary = Text::Levenshtein::Dictionary.new(
    ['receive', 'received', 'deceive'],
    normalize: :nfkc_casefold,
    priority: { 'receive' => 0 }
  )
  dictionary.candidates('recieve', max_distance: 2)
  # => ['receive', 'deceive']
  dictionary.top_k('recieve', 2)
  # => ['receive', 'deceive']
  dictionary.node_count
  dictionary.candidates_with_stats('recieve', max_distance: 2)[:expanded_nodes]

Indexes use a versioned JSON representation. Loading rejects mismatched
versions or normalization configuration and never deserializes arbitrary Ruby
objects.

  json = dictionary.export
  Text::Levenshtein::Dictionary.load(json)

=== Metaphone

  Text::Metaphone.metaphone('BRIAN')
  # => 'BRN'

  Text::Metaphone.double_metaphone('Coburn')
  # => ['KPRN', nil]
  Text::Metaphone.double_metaphone('Angier')
  # => ['ANJ', 'ANJR']

=== Soundex

  Text::Soundex.soundex('Knuth')
  # => 'K530'

=== Porter stemming

  Text::PorterStemming.stem('abatements')  # => 'abat'

=== White similarity

  white = Text::WhiteSimilarity.new
  white.similarity('Healed', 'Sealed')   # 0.8
  white.similarity('Healed', 'Help')     # 0.25

Note that some intermediate information is cached on the instance to improve
performance.

== Ruby version compatibility

The library has been tested on Ruby 1.8.6 to 1.9.3 and on JRuby.
